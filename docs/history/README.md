# Project history — optional background

These notes explain how the standalone toolkit came about and what was checked during its first development. They are kept so future maintainers can understand those choices. You do not need to read them to install or use AG.

For current instructions, start with [getting started](../getting-started.md) or the [documentation index](../README.md).

- [Origin and extraction decisions](extraction-assessment.md): what AG kept from its predecessor and what it left behind.
- [Early validation record](validation-results.md): checks performed during initial development, not the status of the latest build.
- [Original Filmcraft adoption plan](filmcraft-adoption.md): an early intended use, not a prerequisite for other projects.

The JSON files record source revisions and file fingerprints. `source-roadmap.patch` preserves the exact uncommitted roadmap change inspected during extraction. They are provenance records, not setup files.
